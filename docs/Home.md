# DaemonCores-Phone documentation

DaemonCores-Phone is currently a research codebase, not a phone distribution release.

## Documentation map

- [Architecture](architecture.md) — what exists now and where future device work connects.
- [Halium integration boundary](halium-delta.md) — requirements that remain between a descriptor and a bootable device.
- [Design decisions](justifications.md) — current choices, constraints, and deferred decisions.
- [Image experiments](minimal.md) — scope of the existing root-level Containerfiles.
- [Kernel-source policy](sources-kernel.md) — evidence required before accepting a device kernel source.
- [Roadmap](../todo/ROADMAP.md) — ordered implementation plan and evidence-based status.
- [Repository README](https://github.com/DaemonCores/DaemonCores-Phone#readme) — concise project status and converter usage.

Older documents described the intended Halium pipeline as if it already existed. The current documentation uses repository paths and executable tests as the definition of implementation status.
